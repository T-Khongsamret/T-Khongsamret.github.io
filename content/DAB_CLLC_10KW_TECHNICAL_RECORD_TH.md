## 1. เริ่มจากงานเปเปอร์ P00167 เดิม

งานเดิมเปรียบเทียบ SPS-DAB กับ Asymmetric CLLC ใน PSIM ภายใต้เงื่อนไข:

- DC link 400 V
- แบตเตอรี่ 250–450 V
- กำลัง 1–6 kW
- สองทิศทาง G2V และ V2G
- 60 คู่เปรียบเทียบ หรือ 120 ผลจำลอง

งานนี้ใช้ศึกษาว่าเมื่อแรงดัน กำลัง และทิศทางเปลี่ยน วงจรใดมีประสิทธิภาพจากแบบจำลองและความเค้นกระแสดีกว่า พร้อมตรวจ timestep, loss sensitivity, model fidelity และความสอดคล้องกับสมการ

ต่อมาอาจารย์ให้งานใหม่ที่มีพิกัดต่างออกไป จึงต้องสร้างการทดลองใหม่ ไม่สามารถยกผลจากเปเปอร์เดิมมาใช้โดยตรงได้

## 2. รับข้อกำหนดงานใหม่ 10 kW

ข้อกำหนดที่ใช้ตลอดงานใหม่คือ:

| รายการ | ค่า |
|---|---:|
| ทิศทางกำลัง | DC Grid → ESS |
| DC Grid | 380 V |
| ESS | 280, 300, 350, 400, 450 V |
| กำลังพิกัด | 10 kW |
| ระดับโหลด | 10, 25, 50, 75, 100% |
| กำลังเป้าหมาย | 1, 2.5, 5, 7.5, 10 kW |
| ความถี่สวิตชิ่ง | 100 kHz |
| อัตราส่วนหม้อแปลง | 1.0857 |
| Dead time | 150 ns |
| MOSFET | Wolfspeed C3M0025065D |
| อุณหภูมิกรณีศึกษา | Tcase 125°C |

แรงดัน 5 ค่า × โหลด 5 ระดับ = **25 เงื่อนไขต่อวงจร**

เมื่อจำลอง DAB 25 เคสและ CLLC 25 เคส จึงได้ **50 ผลจำลอง หรือ 25 คู่เปรียบเทียบ** ไม่ใช่ 50 คู่

## 3. สร้างและตรวจวงจร DAB

วงจร DAB ประกอบด้วย:

- Full bridge ฝั่ง 380 V จำนวน 4 MOSFET
- Full bridge ฝั่ง ESS จำนวน 4 MOSFET
- หม้อแปลงความถี่สูง
- Leakage/transfer inductance \(L_k=9.5\,\mu H\)
- Magnetizing inductance \(L_m=600\,\mu H\)
- Gate signals ที่ 100 kHz พร้อม dead time 150 ns
- การควบคุมกำลังด้วย phase shift

หลักการคือบริดจ์ทั้งสองสร้างแรงดันสี่เหลี่ยม เมื่อแรงดันสองฝั่งเหลื่อมเวลากัน จะเกิดแรงดันคร่อม \(L_k\) และมีกระแสส่งพลังงานจาก DC Grid ไป ESS

ในแต่ละเคสค้นหา phase shift ที่ทำให้ ESS ได้รับกำลังใกล้ 1, 2.5, 5, 7.5 หรือ 10 kW ตามเป้าหมาย

## 4. เพิ่มสัญญาณวัดใน PSIM

แต่ละวงจรมีสัญญาณสำหรับวัด:

| ค่าที่ต้องการ | วิธีวัด |
|---|---|
| Phase shift | เวลาระหว่างขอบ gate สองบริดจ์ × 360 × 100 kHz |
| IL RMS | RMS ของกระแส \(L_k\) สำหรับ DAB หรือ \(L_{r1}\) สำหรับ CLLC |
| IL peak | ค่าสูงสุดของ \(|I_L|\) |
| Primary RMS | RMS กระแสขดปฐมภูมิ |
| Secondary RMS | RMS กระแสขดทุติยภูมิ |
| กำลังเข้า | Average ของ \(V_{DC}I_{DC}\) |
| กำลังออก | Average ของ \(V_{ESS}I_{ESS}\) |
| Conduction loss | ผลรวมค่าเฉลี่ย Pcond ของ MOSFET และ diode Q1–Q8 |
| Switching loss | ผลรวมค่าเฉลี่ย Psw ของ MOSFET และ diode Q1–Q8 |
| Gate loss | ค่าประมาณจาก \(8Q_gV_gf_s\) |
| ZVS diagnostic | ตรวจ VDS และทิศกระแสก่อนขอบเปิด gate |
| Nonactive current | ส่วนกระแสที่ไม่ส่งกำลังจริงตามตัวชี้วัดของแบบจำลอง |
| Port efficiency | \(100P_{out}/P_{in}\) |
| Modeled efficiency | \(100P_{out}/(P_{out}+P_{CON}+P_{SW}+P_{gate})\) |

ทุกค่าใช้ช่วง steady state เดียวกัน โดยทั่วไปใช้ 200 µs หรือ 20 คาบ ที่ 100 kHz ไม่ใช้ค่าจากช่วงสั้นเพียงบางส่วนของคาบ

## 5. สร้างผล DAB 25 เคส

DAB ถูกจำลองครบทั้ง 25 เงื่อนไข บันทึก:

- ไฟล์วงจร `.psimsch`
- ผลคลื่น `.smv`
- ตัวเลขผลลัพธ์และ qualification
- ค่ากระแส กำลัง loss และประสิทธิภาพ
- สถานะ ZVS screening
- ค่า timestep ที่โปรแกรมใช้จริง
- hash ของไฟล์ต้นทาง

ตอนแรก DAB ผ่าน 23/25 เคส อีกสองเคสยังต้องตรวจเพิ่ม โดยเฉพาะ DAB 280 V / 5 kW ซึ่ง phase ชุดแรกให้ 5,049.83 W หรือผิด +0.997% เกินเกณฑ์ ±0.5%

จึงกำหนดแผนค้นหา phase เพิ่มล่วงหน้า แล้วทดลองจริงทุกจุด ไม่แก้ตัวเลขภายหลัง สุดท้ายพบ phase 10.656° ให้กำลัง 5,024.303 W หรือผิด +0.486% จึงผ่านเกณฑ์กำลัง แต่ยังระบุคำเตือน ZVS แยกไว้

## 6. สร้างวงจร CLLC

หลังจาก DAB จึงสร้าง Asymmetric CLLC สำหรับเมทริกซ์ 10 kW เดียวกัน โดยมี:

- Full bridge สองฝั่งเหมือนกันในระดับโครงสร้าง
- Resonant tank แทน transfer inductor ของ DAB
- \(L_{r1}=16.245\,\mu H\)
- \(C_{r1}=243.767\,nF\)
- \(L_{r2}=14.89125\,\mu H\)
- \(C_{r2}=265.928\,nF\)
- \(L_m=70.395\,\mu H\)

ค่าชุดนี้เป็น implementation ที่ใช้ในการศึกษา ไม่ใช่ผล optimization ที่รับรองว่าดีที่สุดของ CLLC

CLLC มีกระแสเรโซแนนซ์และพลังงานสะสมใน L–C ทำให้รูปคลื่นและการเข้าสู่ steady state ต่างจาก DAB จึงไม่สามารถใช้วิธีเริ่มต้นและระยะเวลาจำลองเหมือน DAB ทุกกรณีได้ทันที

## 7. ปัญหาที่พบใน CLLC รอบแรก

รอบแรก CLLC ผ่าน 21/25 เคส ทำให้เปรียบเทียบได้เพียง 20/25 คู่ ปัญหาหลักคือ:

- ช่วงค้นหา phase เดิมแคบเกินไป โดยเฉพาะโหลดต่ำ
- บางจุดต้องใช้ phase ติดลบ แต่การค้นหาเดิมเกือบจำกัดเฉพาะค่าบวก
- Power–phase response บางช่วงไม่เป็นเส้นตรงหรือไม่ monotonic
- บางเคสกำลังใกล้เป้า แต่ state ภายในถังเรโซแนนซ์ยังไม่นิ่ง
- บางคู่มี timestep จริงของ DAB และ CLLC ไม่เท่ากัน

ตัวอย่าง CLLC 280 V / 1 kW รอบแรกได้ 994.913 W หรือผิด −0.509% จึงไม่ผ่านเพราะเกินขอบเขตเพียงเล็กน้อย หลังค้นหาใหม่ที่ phase −1.143° ได้ประมาณ 1,000.97 W หรือ +0.097% และผ่านเกณฑ์อื่นด้วย

## 8. กำหนดกติกาซ่อมผลก่อนรันใหม่

เพื่อไม่ให้เลือกผลตามใจ ได้เขียน protocol ก่อนรันเพิ่มเติม:

- Power error ต้องไม่เกิน ±0.5%
- Power drift ระหว่างหน้าต่างต้องไม่เกิน 0.1% ของกำลังเป้าหมาย
- RMS และ included loss drift ไม่เกิน 0.1%
- Peak drift ไม่เกิน 1%
- State residual ไม่เกิน 0.5%
- Half-window power drift ไม่เกิน 0.5%
- Gate pattern, dead time และจำนวน switching events ต้องถูกต้อง
- VDS และ ID ต้องไม่เกิน stress screen ที่กำหนด
- ต้องเก็บทุก attempt รวมทั้ง attempt ที่ไม่ผ่าน
- หากใช้ timestep เล็กลง วงจรอีกฝั่งของคู่เดียวกันต้องรันที่ timestep จริงเดียวกัน
- ห้ามลดเกณฑ์เพื่อทำให้เคสผ่าน

## 9. แก้การค้นหา phase

ขยายช่วง phase ของ CLLC เป็น −10° ถึง 85° และใช้วิธี bracket/interpolation/bisection จากผล PSIM จริง

เปลี่ยนเฉพาะ phase เพื่อหากำลังเป้าหมาย โดยคง:

- แรงดัน
- ความถี่
- dead time
- MOSFET
- resonant components
- อุณหภูมิ
- เกณฑ์ผ่าน

ทิศทางกำลังตรวจจากกำลังที่พอร์ต ไม่ตัดสินจากเครื่องหมาย phase เพียงอย่างเดียว เพราะ phase ติดลบไม่ได้หมายความว่ากำลังต้องไหลย้อนเสมอในวงจร CLLC ที่มี tank และนิยามสัญญาณเฉพาะ

## 10. ตรวจปัญหา initialization และ settling

เคสสำคัญคือ CLLC 450 V / 1 kW ซึ่งตอนเริ่มต้นยังไม่นิ่ง:

| เวลาสะสม | Power error | State residual | ผล |
|---|---:|---:|---|
| 10 ms | +0.576% | 13.420% | ไม่ผ่าน |
| 20 ms | +0.314% | 0.870% | ยังไม่ผ่าน state |
| 30 ms | +0.393% | 0.131% | ผ่าน |
| 40 ms | +0.384% | 0.0349% | ผ่าน |
| 50 ms | +0.385% | 0.00323% | ผ่านและนิ่งขึ้น |

จึงจำลองต่อแบบ checkpoint chain 5 ช่วง ช่วงละ 10 ms โดยส่งต่อ state จริง ตรวจ hash ระหว่างทุกช่วง และตรวจว่าการต่อสถานะไม่ขาด

นี่แสดงว่าการ “ได้กำลังใกล้ 1 kW” อย่างเดียวไม่พอ ต้องรอให้พลังงานใน L และ C เข้าสู่ periodic steady state ด้วย

## 11. ตรวจ timestep ให้ยุติธรรม

บันทึกทั้ง requested timestep และ realized timestep จากไฟล์จริง

บางเคสแม้ขอ 0.5 ns แต่ solver ให้ข้อมูลจริงประมาณ 0.25 ns จึงรันวงจรคู่เทียบอีกฝั่งที่ความละเอียดเดียวกัน ก่อนอนุญาตให้นำมาจัดอันดับ

จุดนี้สำคัญเพราะถ้า DAB ใช้ timestep ละเอียดกว่า CLLC หรือกลับกัน ค่า switching event, peak และ loss อาจเปรียบเทียบอย่างไม่ยุติธรรม

## 12. ตรวจผลจำลองและหลักฐานอีกครั้ง

หลังซ่อมครบ ได้ตรวจซ้ำจาก native PSIM waveform:

- ผลจำลอง 50/50 มีไฟล์ต้นทาง
- คำนวณตัวเลขจาก waveform ซ้ำตรง 50/50
- Hash แหล่งข้อมูลตรง 50/50
- DAB ผ่าน 25/25
- CLLC ผ่าน 25/25
- จับคู่ได้ 25/25
- HOLD เหลือ 0
- ตรวจ low-V turn-on events รวม 8,000 เหตุการณ์
- ตรวจพารามิเตอร์ dead time, ratio และ gate pattern ครบ 50 records

ผลที่ผ่านเรียกว่า **qualified numerical result** หมายถึงผ่านเกณฑ์ตัวเลขของโครงการ ไม่ได้หมายถึงผ่านมาตรฐานรับรองฮาร์ดแวร์

วงจรอ่านง่ายมีสมบัติทางไฟฟ้าและค่าตั้งตรงกับต้นฉบับ แต่ไม่ได้หมายความว่าได้นำสำเนาจัดหน้าใหม่ทั้ง 50 ไปรันซ้ำอีกครั้ง ผลตัวเลขยังอ้างจากวงจรต้นทางและ waveform ที่ตรวจ hash แล้ว

## 15. ผลเปรียบเทียบที่ได้

ภายใต้บัญชี loss ที่รวมเฉพาะ conduction, switching lookup และ gate estimate:

- CLLC มี modeled efficiency สูงกว่า 20 คู่
- DAB สูงกว่า 5 คู่

แต่ห้ามสรุปว่า CLLC ดีกว่า DAB โดยทั่วไป เพราะนี่เป็นการเปรียบเทียบ implementation ที่กำหนด และ loss ยังไม่ครบทุกองค์ประกอบ

แนวโน้มสำคัญคือ:

- ที่ 280–300 V และโหลดต่ำถึงกลาง CLLC มักมี switching loss ต่ำกว่า
- ที่ 350 V อัตราส่วนแรงดันใกล้หนึ่ง DAB ทำงานได้ดีและผลหลายคู่สูสี
- ที่ 400–450 V ผลชุดนี้มักให้ CLLC มี modeled efficiency สูงกว่า โดยเฉพาะเมื่อ switching loss ของ DAB สูง
- เมื่อโหลดสูง conduction loss เพิ่มขึ้นตามกระแส
- ค่าประสิทธิภาพที่ต่างกันน้อยมาก เช่น 0.027 pp อาจเปลี่ยนได้หากเพิ่ม magnetic/passive loss ที่ยังไม่ได้รวม

ดูคำอธิบายทุกคู่ได้จาก **รายงานวิเคราะห์ภาษาไทย** *(อ้างถึงไฟล์หลักฐานภายในเครื่องต้นทาง ไม่ได้เผยแพร่พร้อมเว็บไซต์)*

## 16. สิ่งที่พิสูจน์ได้ในตอนนี้

พิสูจน์ได้ว่า:

- มีผล native PSIM ครบ 50 records
- ทั้ง 50 records ผ่านเกณฑ์เชิงตัวเลขที่ประกาศไว้
- เปรียบเทียบได้ครบ 25 คู่
- กำลังอยู่ภายใน ±0.5%
- ผลอยู่ใน steady state ตามเกณฑ์
- คู่เปรียบเทียบใช้ timestep จริงตรงกัน
- สมการ Excel คำนวณย้อนกลับได้
- ทุกผลมีเส้นทางย้อนกลับไปยัง waveform และวงจรต้นทาง

## 17. สิ่งที่ยังพิสูจน์ไม่ได้

ยังไม่สามารถเรียกผลนี้ว่า efficiency ของฮาร์ดแวร์จริง เพราะยังขาด:

- Transformer copper loss
- Transformer core loss
- Loss ของ external/resonant inductors
- ESR loss ของ resonant capacitors
- Gate-driver quiescent loss
- Auxiliary และ cooling loss
- Thermal network ของฮาร์ดแวร์จริง
- การวัด ZVS จาก VDS–ID overlap จริง
- ต้นแบบฮาร์ดแวร์และผลจาก power analyzer

ดังนั้น Modeled efficiency เป็นผลภายใต้บัญชี loss ที่ระบุ ส่วน Port efficiency เป็นผลจากกำลังเฉลี่ยที่พอร์ตในแบบจำลอง ทั้งสองไม่จำเป็นต้องเท่ากัน เพราะ thermal loss lookup ถูกคำนวณแยกและไม่ได้ถูกป้อนกลับเป็นการสูญเสียพลังงานครบถ้วนใน electrical network เดียวกัน
