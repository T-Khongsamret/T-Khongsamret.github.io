# วิธีส่งผลงานใหม่เข้าเว็บไซต์ — Thantham Khongsamret

คุณสามารถส่งไฟล์หรือ URL มาในแชตได้เลย พร้อมคำอธิบายสั้น ๆ เช่น:

> เพิ่มลงเว็บไซต์: กิจกรรมอาสา [ชื่อกิจกรรม] วันที่ [วัน/เดือน/ปี] สถานที่ [สถานที่] ผมทำหน้าที่ [บทบาทจริง] สิ่งที่ทำ [งานที่ทำ] สิ่งที่ได้เรียนรู้ [1-3 ประโยค] ไฟล์ประกอบ [PDF/รูป/คลิป/ลิงก์] เผยแพร่รูปและชื่อบุคคลในภาพได้/ไม่ได้

## ข้อมูลที่จำเป็นสำหรับรายการใหม่
- ชื่องานหรือหัวข้อ; หมวด: Research / Engineering / Learning / Community / Leadership / Field Visits
- วันที่จริงหรือระยะเวลา และสถานที่ (ถ้ามี)
- บทบาทที่ทำจริงและผลลัพธ์ที่ตรวจสอบได้
- หลักฐาน เช่น PDF, เกียรติบัตร, ภาพ, รูปโปรเจกต์, ลิงก์ที่เปิดสาธารณะ
- สิทธิในการเผยแพร่ไฟล์ รูป และข้อมูลส่วนบุคคลของคนอื่น
- ต้องการไทยอย่างเดียวหรือสองภาษา (ค่าเริ่มต้น: สองภาษา)

## ขั้นตอนที่ระบบเว็บจะทำ
1. ตรวจเนื้อหาและสิทธิการเผยแพร่ แยกข้อเท็จจริงออกจากสิ่งคาดการณ์
2. จัดรูป/ไฟล์/ลิงก์ลงหมวดและเพิ่มใน `content/portfolio.json`
3. สร้างหน้าเนื้อหาแยกภาษาและ Abstract/คำอธิบาย พร้อม hashtags เฉพาะเรื่อง
4. สร้างปุ่มเปิดดู/ดาวน์โหลดเอกสาร เมื่อไฟล์นั้นอยู่บนเว็บจริง
5. เพิ่ม Schema.org, canonical, hreflang, sitemap, Open Graph และลิงก์ภายใน
6. เผยแพร่ GitHub Pages แล้วตรวจการทำงาน
7. ร่างข้อความสั้นสำหรับ LinkedIn / Facebook / แพลตฟอร์มที่รองรับ ปรับให้เหมาะแต่ละแพลตฟอร์ม
8. ส่งโพสต์ภายนอกต่อเมื่อบัญชีเชื่อมต่อพร้อม สิทธิ์การโพสต์ใช้งานได้ และคุณเห็นชอบข้อความนั้น
9. ถ้าเป็นงานวิชาการ ให้ปรับ ORCID / Scholar / ResearchGate เฉพาะรูปแบบและสถานะที่แพลตฟอร์มนั้นรองรับ
